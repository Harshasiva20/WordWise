# 📖 WordWise – Mini Dictionary

**WordWise** is a simple and interactive mini dictionary application that helps users understand the **meaning of words** quickly and easily.

The user can enter a word and get its meaning, making it a useful tool for improving vocabulary and learning new words.

## 🌟 Features

* 🔍 Search for the meaning of a word
* 📖 Simple and easy-to-use interface
* ⚡ Quick word lookup
* 💻 Clean and user-friendly design
* 📱 Easy to use for everyday vocabulary learning

## 🛠️ Technologies Used

* **HTML**
* **CSS**
* **JavaScript**
* **Antigravity** – Used to assist in building the application

## 🔄 How It Works

```text
User enters a word
        ↓
WordWise processes the search
        ↓
The meaning of the word is retrieved
        ↓
The meaning is displayed to the user
```

## 🎯 Purpose

The main purpose of WordWise is to create a simple digital dictionary that makes **learning and understanding new words easier**.
